# Changelog

## 1.0.1 - 2026-08-14

- Allow `repokit-backup` releases from 0.1.0 through 1.0.0 inclusive and validate against 1.0.0.

## 1.0.0 - 2026-08-13

- Added a supported release workflow with immutable wheel, source archive, and checksum assets.
- Declared compatible internal package lines: common 1.x, dmp 1.x, and backup 0.1.x.
- Removed the source-tree dependency fallback and use the public `repokit-common.run_command` API.
- Added Python 3.10 and 3.12 CI against published dependency wheels.
- Excluded generated bytecode from source and wheel artifacts.

## 0.1.0 - 2026-08-13

- Legacy baseline release.
